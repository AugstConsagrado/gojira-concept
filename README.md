# GOJIRA — Instinto & Consciência

Site editorial independente sobre a banda Gojira, criado como projeto de portfólio de Erick Augusto. Concepção e direção de Erick; desenvolvimento com apoio de IA. Projeto não oficial, sem vínculo com a banda.

## Executar

Requisito: Node.js 22 ou superior. Não há dependências para instalar.

```bash
npm start
```

Abra http://127.0.0.1:3003. Também é possível servir a pasta `dist/` com qualquer servidor HTTP estático. O projeto usa HTML, CSS e JavaScript, com imagens e fontes locais.

## Experiência

- Abertura editorial com fotografia, tipografia expressiva e movimento discreto.
- Integrantes com funções e detalhes expansíveis.
- Sete álbuns com capas originais, anos, links de escuta e diálogos com faixas.
- No PC, a rolagem normal percorre a discografia horizontal e revela as capas lateralmente, sem rotação, ampliação ou filtros de suavização.
- No celular, álbuns em sequência vertical e todos os anos da cronologia em grade, sem depender de arraste lateral.
- Onze marcos de 1996 a 2025, com tonalidades por álbum e destaque para a mudança de Godzilla para Gojira. Sem imagens espelhadas no fundo.
- Além do Som reúne quatro contextos musicais, fontes e elementos decorativos de globo, baleia e árvore.
- Menu móvel, foco visível, link de pulo, navegação por teclado e preferência de movimento reduzido.
- Rodapé com GitHub, Instagram e LinkedIn de Erick e créditos das imagens.

## Verificar

```bash
npm test
```

Os quatro testes verificam discografia, associação das faixas, cronologia e contextos musicais. A conferência visual foi feita em navegador de computador e larguras móveis de 390 e 360 pixels; não houve teste em aparelho Android físico. Consulte `VERIFICACAO.md` e `ENTREGA.md`.
